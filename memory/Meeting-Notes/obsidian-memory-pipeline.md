# Obsidian + Hermes Memory Pipeline
_Added during weekly memory consolidation on 2026-08-02 from a recent session clarification._

## Summary
- **Obsidian** remains the long-form notebook / archive.
- **Hermes live memory / Mnemosyne** is the fast recall layer.
- **Cron auto-save** bridges the two by copying chat/session material into the vault.

## Practical takeaway
- Treat the vault as the durable knowledge base.
- Keep injected memory lean and pointer-based.
- Use live memory for high-signal facts that need to be recalled every session.
