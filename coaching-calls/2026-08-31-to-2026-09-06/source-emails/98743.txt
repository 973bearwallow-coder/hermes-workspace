The keynote moves to a ballroom, and hands-on training becomes an elective to improve internet stability. Topics AI Development Strategies - Problem: AI Agent Memory & Context - Ernest Mockus's challenge: Losing context when switching Claude Code chats, requiring frequent re-alignment. - Jeff Wurfel's solution: Use Claude Chat to generate prompts for Claude Code. - Jeff is also developing a system to audit AI-generated code for quality and remove unused sections. - Solution: AI for Strategic Planning - Jeff's advice: Use AI to define goals and strategy before coding. - This multi-step process is more effective than single-step prompting for complex tasks like migrating a project to AgenticOS. Project Showcase: Patrick Thomas - Project: A mobile companion app for construction estimating software. - Features: Job creation, photo/voice notes, GPS, and export to XML for the desktop app. - Development Process: - Built with GrokBuild and Cursor, demonstrating AI's ability to empower non-developers. - Used Cursor's GrokBot to continue development after exhausting GrokBuild tokens. - Note: GrokBuild's pay-as-you-go tokens are expensive (~$7/build) compared to subscription tokens. Project Showcase: John Mackenzie - Project: "Black Snow Intelligence" (BSI), a platform assessing company privacy and data compliance. - Methodology: - Scrapes public websites for 42 data points (ToS, privacy notices, tech stack). - Generates deep-dive reports (200–300 pages) and a "Security Pet" browser extension for real-time scans. - Scale: 91,706 company assessments completed, growing by 30–40k/day. - Key Insight: GrokBot VPS for Cost Savings - The core value of GrokBot is its free, powerful VPS (8 CPUs, 16GB RAM), not the AI model itself. - Strategy: Use Claude.ai for high-level strategy → Use GrokBot's VPS for CPU-intensive tasks (e.g., scraping, data enrichment). - Result: Achieved the equivalent of a week's Claude Max plan in one day for a $20/mo Cursor subscription.
